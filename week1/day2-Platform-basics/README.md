📌 What is Salesforce Platform?
Salesforce Platform is a cloud-based development platform that allows businesses to create, customize, and manage applications efficiently using objects, apps, tabs, and automation features.
It helps organizations to:


Build business applications quickly


Manage and store data securely


Customize applications based on requirements


Automate business operations


Improve productivity and workflow management



🧩 Core Salesforce Concepts
📱 App
An App is a group of related tools, objects, and functionalities designed for a particular business purpose.
Example: College Administration App
🗂️ Object
An Object is used to store information in Salesforce, similar to a table in a database.
Example: Student Details
📑 Tab
A Tab helps users open and access objects, records, or applications easily within Salesforce.

🔄 Relationship Between CRM and Platform
CRM components such as Accounts, Contacts, and Opportunities are maintained as Objects inside Salesforce Apps. Users interact with this data through Tabs.

⚙️ Configuration vs Coding
🔹 Configuration (Without Coding)
Configuration means customizing Salesforce using built-in tools without writing code.
Examples:


Creating custom fields


Designing workflows


Setting up page layouts


Automating simple processes


🔹 Coding (Apex Programming)
Coding is used when advanced customization and business logic are required.
Examples:


Building custom automation


Creating advanced validations


Developing complex business functionality
